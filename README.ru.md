# lanpad

**[English](README.md) · [Deutsch](README.de.md) · [Русский](README.ru.md)**

Телефон становится тачпадом, клавиатурой и пультом управления медиа для
компьютера на Linux. Через твой же Wi-Fi. Без облака, без учётных записей,
без рекламы.

---

## Зачем это

У меня Fedora на MacBook 2015 года, крышка закрыта, картинка выведена на
27-дюймовый монитор. Конфигурация отличная, изъян один: с закрытой крышкой
клавиатура и трекпад заперты внутри. Тянуться не к чему.

Мы так смотрим фильмы с девушкой, и мне хотелось переключить сцену, не вставая
с кровати. Телефон у меня iPhone, а все приложения, которые я перепробовал,
оказались либо забиты рекламой, либо не работали, либо требовали
зарегистрироваться — ради того, чтобы подвигать курсор в соседней комнате.

Отсюда этот проект. Собран за день в паре с Claude: код по большей части
написан моделью, проектирование и разбор находок мои. Сказать это прямо
честнее, чем оставить догадываться по истории коммитов.

## Что умеет

- **Тачпад** — курсор, нажатия, прокрутка двумя пальцами, перетаскивание,
  полоса у края для прокрутки одной рукой
- **Клавиатура** — набор, модификаторы, сочетания и поле вставки для всего,
  что раскладка не наберёт напрямую, включая кириллицу
- **Медиа** — пуск, пауза, следующий, предыдущий, громкость, а также текущий
  трек с обложкой и перемоткой
- **Консоль на компьютере** — окно в лаунчпаде с QR-кодом для спаривания,
  состоянием связи и управлением службой

## Как устроено

Агент работает на компьютере и раздаёт приложение по локальной сети. Телефон
открывает его в браузере и добавляет на домашний экран. Ввод внедряется через
`/dev/uinput`, медиа берётся из MPRIS — работает со Spotify, VLC и с видео,
открытым во вкладке браузера.

Наружу не уходит ничего. Сервера посередине нет, потому что ему нечего было бы
там делать.

```
  компьютер ── агент ──┐
                       │  твой Wi-Fi
  телефон ── браузер ──┘
```

## Установка

Fedora и другие дистрибутивы Linux с systemd.

`evdev` собирает C-расширение, поэтому нужны инструменты сборки. На чистой
Fedora именно это остановит тебя первым:

```bash
sudo dnf install python3-devel gcc
pipx install lanpad
lanpad --install-service
```

Дальше открой **lanpad** в лаунчпаде, отсканируй QR-код телефоном и добавь
страницу на домашний экран.

Если сеть сменилась — другой Wi-Fi, режим модема, перезагруженный роутер —
окно консоли покажет новый код само. Перезапускать ничего не нужно.

## Состояние

**Работает:** агент, консоль на компьютере, спаривание, курсор, клавиатура,
громкость, буфер обмена.

**В работе:** приложение на телефоне переписывается. Медиа-панель, фейдеры,
полоса прокрутки у края и двуязычный интерфейс спроектированы и описаны, а
сторона агента уже говорит на нужном им протоколе. То приложение, что
поставляется сегодня, — прототип, и половину этого пока не использует.

Релиз не помечен: пометить его сейчас значило бы пообещать то, чего
приложение не делает.

## Ограничения

О чём стоит знать до установки:

- **Только локальная сеть.** Это выбор, а не недоделка. Удалённый доступ
  означал бы сервер-посредник и зависимость от того, что кто-то будет его
  поддерживать.
- **Пока только Linux.** Слой платформы разделён так, чтобы Windows и macOS
  добавлялись без правок протокола и приложения.
- **Ссылка привязана к адресу компьютера.** Если DHCP выдаст новый, иконка на
  домашнем экране будет вести в никуда. Закрепи адрес на роутере или открой
  консоль и отсканируй свежий код.
- **Любой в твоей сети, у кого есть токен, управляет твоей клавиатурой.**
  Подробнее ниже.

## Про безопасность, честно

Модель угроз прямым текстом — инструмент, который печатает на твоей машине,
этого заслуживает:

- Токен спаривания едет в адресе страницы, а значит попадает в историю
  браузера на телефоне. Это цена спаривания по QR-коду.
- **Любой, кто в твоём Wi-Fi и знает токен, может печатать на твоём
  компьютере.** Второго рубежа нет. Дома это осознанный размен; в кафе такое
  запускать не нужно.
- Консоль — окно с QR-кодом и управлением службой — доступна только с самого
  компьютера и никогда из сети.
- Файл токена лежит в каталоге данных с правами `0600`. Это защищает его от
  других пользователей, но не от других процессов твоего же.
- Любая местная программа может назваться медиаплеером и подсунуть агенту путь
  к обложке. Отдаются только настоящие картинки и только до определённого
  размера.

## Разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/pytest && .venv/bin/ruff check .

cd web && npm install && npm test && npm run build
```

Фронт собирается в `src/lanpad/web`, откуда его раздаёт агент. В именах файлов
сборки стоит хеш содержимого, и агент разрешает им вечное кэширование только
если хеш шестнадцатеричный — поменяешь настройку сборки, и обновления
перестанут доходить до спаренных телефонов.
